# SmishFuse, шаг 1: отчёт по данным

Сгенерировано скриптом `src/data/report.py` из `reports/stats/*.json`. Воспроизведение описано в `README.md`: `uv venv --python 3.11 .venv && uv pip install --python .venv/bin/python -r requirements.txt`, затем `.venv/bin/python src/data/run_all.py`. Сырые файлы скачиваются автоматически и сверяются по sha256. Модели не обучались.

Метод дубликатов везде один: текст → lowercase + схлопывание пробельных символов; точный дубликат = совпадение нормализованного текста; почти-дубликат = точный коэффициент Жаккара ≥ 0.9 на множествах символьных 5-грамм. MinHash LSH (datasketch, 128 перестановок, порог кандидатов 0.7) используется только для поиска кандидатов, каждая пара проверяется точным Жаккаром. Группы дубликатов = компоненты связности.

## 4. Дубликаты внутри датасетов и конфликты меток

Правило. В группе без конфликта остаётся сообщение с наименьшим id, остальные удаляются. В группе с разными метками проводится голосование большинством: остаётся сообщение с наименьшим id среди носителей метки большинства, остальные члены большинства удаляются как дубликаты, меньшинство — как `label_conflict_minority`. Если голоса разделились поровну, группа удаляется целиком (`label_conflict_tie`). Метки не переписываются: оставленное сообщение уже имеет метку большинства. Все удалённые строки лежат в `reports/removed/<name>_dedup.csv` (reason, group_id, kept_id, jaccard_to_kept), конфликтные группы целиком — в `reports/conflicts/<name>.csv` (колонка resolution).

## 8. Проблемы и что осталось сделать вручную

### Проблемы в данных

- **Mendeley: метки в разном регистре** ({'Smishing': 616, 'Spam': 23, 'ham': 4844, 'smishing': 22, 'spam': 466}). Привёл к нижнему регистру; суммы сходятся с описанием.
- **Mendeley: 145 сообщений содержат символ замены U+FFFD**: кодировка была потеряна ещё в исходном файле, восстановить текст нельзя. Сообщения оставлены как есть.
- **Mendeley: у 254 сообщений пробелы в начале или конце текста, 153 начинаются с табуляции.** Похоже на артефакт OCR или конвертации. Текст в данных не менялся; при поиске дубликатов пробелы нормализуются.
- **Mendeley почти целиком пересекается с UCI**: 4914 из 5739 сообщений после дедупликации. Часть сообщений с меткой UCI `spam` в Mendeley размечена как `smishing` (см. таблицу в разделе 5), то есть граница spam/smishing задана разметкой Mendeley.
- **Mendeley: все конфликтные группы (41) — это spam против smishing** на одинаковых или почти одинаковых текстах. Ничьих: 40, решено большинством: 1. Граница между этими классами размечена непоследовательно; для `label_binary` эти конфликты несущественны (оба класса = 1), но группы с ничьей всё равно удалены.
- **MOZ-Smishing: конфликты ham/smishing на одинаковых текстах** (групп: 4, все с ничьей, удалены). На HF лежит только `test.csv`, официального train/test нет. Источники сообщений: {'fb': 400, 'sms': 2161}.
- **MOZ-Smishing: лицензия creativeml-openrail-m** рассчитана на модели, а не на датасеты. Условия использования данных стоит уточнить.
- **Super SMS: размер не совпадает с заявленным.** В файле 67010 строк (в статье 67018, в аннотации «more than 68K»). Валидных 67008: {'empty_text': 1, 'missing_label': 1} строк отброшены (пустая метка или пустой текст). Классы {'ham': 40830, 'spam': 26178} против 40837/26181 в статье тех же авторов.
- **Super SMS: кодировка смешанная.** 2 байта не из UTF-8 прочитаны как cp1252. 166 сообщений содержат управляющие символы C1 (U+0080–U+009F), то есть исходный текст уже был испорчен на стороне источника (mojibake). Не исправлялось.
- **Super SMS: предобработка неоднородная.** 14949 сообщений (22.3%) состоят только из строчных латинских букв, цифр и пробелов: похоже, их уже привели к нижнему регистру и убрали пунктуацию (например, `httphikein`). Остальные выглядят как исходные. Модель может научиться отличать источник по стилю.
- **Super SMS: группа шаблона hike** (ham 1, spam 36) решена большинством: оставлено одно spam-сообщение, остальные spam удалены как почти-дубликаты, ham — как меньшинство.
- **Super SMS содержит UCI и Mendeley**: 4381 сообщений Super SMS совпадают с UCI и 4280 — с Mendeley. Для кросс-датасетных экспериментов с Mendeley сделан вариант `super_sms_clean` (61225 сообщений, раздел 6). Полный `super_sms` остаётся с этими пересечениями.
- **Super SMS: лицензия данных не указана.**
- **Цепочки в компонентах связности**: каждое звено имеет J ≥ 0.9, но крайние члены группы могут быть менее похожи друг на друга (минимальный J к оставленному представителю виден в `jaccard_to_kept`).
- **langdetect** на коротких SMS даёт шум (af, so, cy и т. п.); доли языков приблизительные.
- **Mendeley ∩ UCI**: наша цифра не совпадает с литературной (4753, обзор Pritom et al., arXiv:2604.11429: 4199 ham и 554 spam, метод подсчёта не описан); указываем обе (см. раздел 5).
