# Paper source (AMIS, Natural Sciences Publishing)

Self-contained LaTeX project for Overleaf: upload the folder (or `paper.zip`) and compile `main.tex`.
The journal sample is built with `latex` (DVI) and EPS figures; in Overleaf choose the compiler
"LaTeX" (pdfLaTeX also works, figures are provided as both EPS and PDF).

- `NSP1.cls`, `everyshi.sty`, `psfig.sty`, `logo7pt.eps`: journal template files (sample of 2024 from
  naturalspublishing.com, unchanged).
- `main.tex`: front matter and the order of sections; `sections/*.tex`: the text.
- `numbers.tex`: every number of the text, generated by `tools/paper_numbers.py` from `results/`, `reports/`
  and `configs/`. The text uses `\val{key}` only; no number is typed by hand.
- `references.bib`: verified references (DOI, arXiv ID, DataCite or the official proceedings page; see
  `refs_candidates.txt`). `bibliography.tex` is generated from it in citation order by
  `tools/make_bibliography.py` in the journal style.
- `check_numbers.py`: fails if `numbers.tex` or a generated table differs from the result files, if a
  `\val` key is undefined, if a number is typed by hand, if an em dash appears, or if the abstract is
  longer than 200 words.

Regenerate and check (from the repository root):

    .venv/bin/python paper/tools/paper_numbers.py
    .venv/bin/python paper/tools/make_bibliography.py
    .venv/bin/python paper/check_numbers.py
