# Paper source (MDPI Information, article)

Self-contained LaTeX project for Overleaf: upload `paper_mdpi.zip` (repository root, built by
`tools/make_zip.py`) and compile `main.tex` with pdfLaTeX. The AMIS version in `paper/` is a separate project.

- `Definitions/`: MDPI class files from `MDPI_template_ACS.zip` (unchanged); `template.tex` and `template.pdf`
  are the template sample, kept for reference and not needed to compile.
- `main.tex`: front matter (journal `information`, type `article`) and the order of sections;
  `sections/*.tex`: the text; `sections/backmatter.tex`: MDPI back matter (placeholders in square brackets).
- `numbers.tex`: every number of the text, generated by `tools/paper_numbers.py` from `results/`, `reports/`,
  `configs/` and code constants, with checks of the textual claims. The text uses `\val{key}` only.
- `tables/*.tex`: generated by `tools/make_tables.py` (key tables for the main text, full tables for the appendix).
- `figures/*.pdf`: generated by `tools/make_figures.py` (needs `requirements-plots.txt`).
- `figures/cascade_diagram.pdf` (Figure 1) and `Definitions/logo-mdpi.pdf` are precompiled once, so that Overleaf
  needs neither TikZ libraries nor an epstopdf run: `scripts/make_mdpi_assets_kernel.py` builds the Kaggle CPU kernel
  `smishfuse-mdpi-assets` (pdfLaTeX of `assets/cascade_diagram_h.tex`, the figure used, and of
  `assets/cascade_diagram_c.tex`, the alternative kept as `assets/cascade_diagram_alt.pdf`, both with the numbers of
  `numbers.tex`; Ghostscript for the logo; input hashes checked
  in the kernel and in `kaggle/build/smishfuse-mdpi-assets.sha256`). `main.tex` points the class to the PDF logo with
  `\patchcmd`; the class file itself is unchanged, and the EPS logos are not packed into the zip.
- `references.bib`: verified references (DOI, arXiv ID or the official page of the publisher or proceedings;
  see `refs_candidates.txt`). `bibliography.tex` is generated from it in citation order in the ACS style of the
  template by `tools/make_bibliography.py`.
- `check_numbers.py`: fails if `numbers.tex` or a generated table differs from the result files, if a `\val` key
  is undefined, if a number is typed by hand, if an em dash appears, or if the abstract is longer than 200 words.

Regenerate and check (from the repository root):

    .venv/bin/python scripts/make_step8_examples.py      # step 8 outputs -> results/step8 (masked examples)
    .venv/bin/python paper_mdpi/tools/make_figures.py
    .venv/bin/python paper_mdpi/tools/make_zip.py        # runs the generators and the checker, then packs

## Word version (generated from the LaTeX sources)

    .venv/bin/python paper_mdpi/tools/make_docx.py    # -> paper_mdpi.docx (repository root, not committed)
    .venv/bin/python paper_mdpi/tools/check_docx.py   # numbers, tables, numbering, equations, lost text

Needs pandoc (no LaTeX). `word/reference.docx` is made from the MDPI Word template `information-template.dot`
(repository root, an OOXML template: content type switched to a document, body emptied; styles, A4 page set-up,
line numbers, headers and footers kept). `make_docx.py` expands `\val`, numbers sections, figures, tables and
equations as in the PDF, replaces `\ref` and `\cite` by their numbers, converts the figures to PNG at 300 dpi,
runs pandoc (equations as Word equations) and assigns the MDPI styles. `check_docx.py` compares the result with
`numbers.tex` and the LaTeX tables. Intermediate files go to `build_docx/` (not committed).

Submission figures (PDF and TIFF 600 dpi, Figure 1 also SVG; the alternative Figure 1 in `alt/`):

    .venv/bin/python paper_mdpi/tools/make_submit_figures.py   # -> paper_mdpi/figures_submit/
